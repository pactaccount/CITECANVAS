    CiteCanvas Workspace Help

    CiteCanvas helps you keep PDF files together and inspect their original pages.

    1. Add a PDF. Use Add documents in the header.
    2. Open it. In Documents, choose Open to see the full file or expand a file to see its sections.
    3. Read its pages. Use page arrows, thumbnails, zoom, or Text in the document viewer.

    Available now: PDF uploads, document browsing, page viewing, and native text when present.

    Analysis: Ask and Extract use NVIDIA cloud analysis after you enable it. Compare finds native-text changes between two PDFs. Always check model answers against their source pages.

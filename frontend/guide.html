Start with one PDF.

Evid is a PDF workspace for viewing original pages, asking source-linked questions, building small tables, and comparing files.

Your browser has its own workspace. Other tabs in the same browser share it; other browser profiles start separately. No sign-in is required.

Your first five minutes

  1. Open the workspace. It starts on Documents.
  2. Click Upload your first PDF, or Add documents in the top right.
  3. Choose or drag in a PDF. Each file must be 25 MB or smaller. Wait for Ready.
  4. Choose Open in the upload dialog, or close the dialog and choose Open beside your file in Documents.
  5. Turn a page, try zoom, and open Text. Then close the viewer to return to the library.
  6. Use Ask a question, Build a table, or Compare files. Ask and Build a table send selected pages to NVIDIA when AI analysis is left on.

Moving around

The top tabs and sidebar point to the same four pages; they are two ways to navigate. On a narrow screen, the menu icon opens the sidebar. My workspace is the name of this local workspace, not a project-switching control. The small number beside Documents, when present, counts PDF files.

Help opens a short guide and links here. Settings explains this browser workspace and provides Clear this workspace. Browser workspace in the header is a status label, not a button.

Documents: your files

This is your starting page. Before your first upload it shows one upload action. Search, filters, counts, and the table appear after you add a file.

  • PDF files: how many original files you have added.
  • Sections: how many entries are organized inside those files. Currently, a new upload is one whole-file section. It is not automatically split into chapters.
  • To review: sections whose title, type, and page range have not been confirmed.

In the table, the bold parent row is an original PDF. The arrow expands its sections. Open opens the entire file; View opens a section at its starting page. These views use the same original file, so a section is not a second upload.

Review section lets you edit the title, type, and start/end pages. Those review edits currently last only for the browser session. The saved original upload survives a refresh.

Search matches section titles, filenames, and available identifiers. It does not search every word inside the PDF. Type and status filters narrow the list; Clear filters restores it. On a phone, scroll the table sideways to reach all columns and actions.

A repeated upload of identical file contents returns Already in library. Different files with the same filename remain separate.

PDF viewer: the original pages

The viewer opens beside the task on a wide screen and over it on a narrow screen.

ControlWhat it does
Page arrows / page numberMove through the original PDF. Enter a number to jump to a page.
ThumbnailsShow or hide the small page previews; select one to jump.
+ / − / FitEnlarge, reduce, or fit the page to the viewer width. A magnified page can scroll sideways.
TextShow the PDF's native text, if it has any. Scanned image-only pages may have no text; OCR is not enabled.
HighlightsShow or hide a selected citation region. No highlights are expected when you simply open your uploaded PDF.
FullscreenGive the page more room.
Close / EscapeReturn to the workspace. If a dialog is open, Escape closes that dialog first.

“PDF page 3” means the third page in the file. A printed page number on the document may be different.

Available

Ask a question

Choose PDFs, enter a question, and select Ask. AI analysis is selected by default and can be turned off before sending pages to NVIDIA. The answer links to its original PDF page and a model-selected highlight. Check that source before relying on the answer. Unanswerable questions abstain; the screen lists the pages inspected. This is bounded retrieval, not an exhaustive document audit.

Available

Build a table

Choose up to four PDFs and enter one to four details on separate lines. AI analysis is selected by default and can be turned off before sending pages to NVIDIA. Review each value using its source button. Accept for session records your review until refresh; Export CSV downloads the shown values and review status. A field not found on retrieved pages is labeled Not found.

Available

Compare files

Choose two different uploaded PDFs and select Compare files. The table shows added, removed, and changed text with source page links. Export CSV downloads the displayed changes. This compares native PDF text; formatting and visual-only differences are not assessed. Scanned PDFs need native text or OCR before text comparison.

What is saved?

New uploads belong only to this browser workspace and reappear in its other tabs. Use Settings → Clear this workspace to remove its PDFs and in-session results. When you run Ask a question or Build a table with AI analysis on, selected PDF pages are sent to NVIDIA for embeddings and model inference. Embedding vectors and source identifiers are stored in Qdrant when available; local vectors provide a fallback. No document text is stored in Qdrant by this runtime. Viewer position, filters, and review edits are session state.

What to look for during your review

Begin without this guide if you want to test your first impression, then return here when something is unclear.

  1. Is the first action obvious?
  2. After uploading, can you find your file and open the correct page?
  3. Can you tell the original file from its section?
  4. Do page controls and close actions behave as you expect?
  5. Is each page's purpose clear, including what is not ready?
  6. Which labels or controls feel unnecessary?

When you send feedback, tell me which page, what you tried, what you expected, and what happened. You can also quote any wording that feels confusing. No need to review everything at once.
